Named Requirements: Result

Result is a generalization of instances of templates in <type_traits>.

Requirements

A class type T is a Result if it fits into one of following categories:

Category Conditions
TypeResult T::type names a type.
ValueResult T has a constexpr static data member named value.
TraitResult T::trait names a class template which satisfies Trait, such that a TypeResult or ValueResult can be obtained in a finite number of steps for any well-formed sequence of nested template instantiations.

Remarks

The final clause in the conditions for TraitResult is necessary to prevent circular definition, as illustrated by the following contrived example:

{c++}
template <typename T>
struct NotTraitResult {
template <typename U>
using trait = NotTraitResult<U>;
};
