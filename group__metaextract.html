Detailed Description

Extracts the template arguments from a template instantiation.

extract is both a TypeTrait and a MetaTrait. If T is a template instantiation, extract<T>::type is a tuple of its template arguments, and extract<T>::trait is a Trait which rebinds T to template arguments. Otherwise, extract is empty.
