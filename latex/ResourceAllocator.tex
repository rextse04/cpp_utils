A resource allocator is an {\itshape Allocator} which operates on buffer memory allocated from an upstream {\ttfamily std\+::pmr\+::memory\+\_\+resource}. It can be wrapped in {\ttfamily \doxylink{classutils_1_1pmr_1_1allocator__resource}{utils\+::pmr\+::allocator\+\_\+resource}} to act as an {\ttfamily std\+::pmr\+::memory\+\_\+resource}, which is useful when one would like to reuse the same allocation strategy with or without virtual dispatch.\hypertarget{ResourceAllocator_autotoc_md14}{}\doxysubsection{\texorpdfstring{Requirements}{Requirements}}\label{ResourceAllocator_autotoc_md14}
