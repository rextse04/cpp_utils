\doxysubsection{Detailed Description}
Replaces the element at index {\ttfamily Idx} in a tuple type {\ttfamily Tuple} with type {\ttfamily T}. 

The index {\ttfamily Idx} can be negative, which is normalized relative to the tuple size.
