\doxysubsection{Detailed Description}
Rebinds a template instance {\ttfamily T} to {\ttfamily Args}. 

If {\ttfamily T} is in the form {\ttfamily Tmpl\texorpdfstring{$<$}{<}...\texorpdfstring{$>$}{>}}, {\ttfamily rebind\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}\+::type} is {\ttfamily Tmpl\texorpdfstring{$<$}{<}Args...\texorpdfstring{$>$}{>}}. Otherwise, {\ttfamily rebind\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}\+::type} is {\ttfamily T}.
