\doxysubsection{Detailed Description}
A \href{Trait.html}{\texttt{ {\itshape Type\+Trait}}} that applies a {\ttfamily Trait} template to corresponding elements across one or more tuple types. 

This creates a new tuple type where each element is the result of applying {\ttfamily Trait} to the corresponding elements from the input tuples.
