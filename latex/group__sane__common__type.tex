\doxysubsection{Detailed Description}
A \href{Trait.html}{\texttt{ {\itshape Type\+Trait}}} that is similar to usual arithmetic conversion, except that the promotion step is replaced by {\ttfamily utils\+::sane\+\_\+promotion}. 

Given any types {\ttfamily T} and {\ttfamily U}, let {\ttfamily TD} and {\ttfamily UD} be {\ttfamily std\+::decay\+\_\+t\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}} and {\ttfamily std\+::decay\+\_\+t\texorpdfstring{$<$}{<}U\texorpdfstring{$>$}{>}} respectively. Their {\ttfamily \doxylink{group__sane__common__type_structutils_1_1sane__common__type}{sane\+\_\+common\+\_\+type}} {\ttfamily C} is determined through the following steps\+:
\begin{DoxyEnumerate}
\item If any of {\ttfamily TD} and {\ttfamily UD} is not specialized for {\ttfamily std\+::numeric\+\_\+limits}, {\ttfamily C} is {\ttfamily std\+::common\+\_\+type\+\_\+t\texorpdfstring{$<$}{<}T, U\texorpdfstring{$>$}{>}}.
\item Otherwise, if {\ttfamily TD} and {\ttfamily UD} have different widths, {\ttfamily C} is the one with the greater width.
\item Otherwise, if at least one of {\ttfamily TD} and {\ttfamily UD} is unsigned, {\ttfamily C} is the first unsigned type out of the two.
\item Otherwise, {\ttfamily C} is {\ttfamily TD}.
\end{DoxyEnumerate}

In the above, the definition of {\ttfamily width} is identical to that in {\ttfamily \doxylink{group__width__of_structutils_1_1width__of}{utils\+::width\+\_\+of}}.
