\doxysubsection{Detailed Description}
A \href{Trait.html}{\texttt{ {\itshape Value\+Trait}}} that determines if {\ttfamily From} can be converted to {\ttfamily To} without loss of information. 

Calculation is based on {\ttfamily From\+Info} and {\ttfamily To\+Info}, which default to respective instantiations of {\ttfamily std\+::numeric\+\_\+limits}. They can be replaced by class types that provide the same interface as {\ttfamily std\+::numeric\+\_\+limits}. \begin{DoxyRemark}{Remarks}
This does not check if {\ttfamily From} is actually convertible to {\ttfamily To}. 
\end{DoxyRemark}
