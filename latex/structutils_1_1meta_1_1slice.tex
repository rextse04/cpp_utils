Extracts a slice from a tuple type from index {\ttfamily Begin} to index {\ttfamily End} (exclusive). 

Both {\ttfamily Begin} and {\ttfamily End} can be negative indices, which are normalized relative to the tuple size. If {\ttfamily Begin \texorpdfstring{$>$}{>}= End}, an empty tuple is returned.
