Convenience variable template to make an \mbox{[}{\itshape Integer\+Behavior\+Profile}\mbox{]}(Integer\+Behavior\+Profile) for integral arithmetics. 

For every relevant operator {\ttfamily @} and the corresponding functor {\ttfamily F} (supplied in template parameters), the synthesized functor {\ttfamily op} behaves as follows\+:
\begin{DoxyEnumerate}
\item If {\ttfamily @} is a binary operator, {\ttfamily op(a, b)} is equivalent to {\ttfamily F(static\+\_\+cast\texorpdfstring{$<$}{<}const C\&\texorpdfstring{$>$}{>}(a), static\+\_\+cast\texorpdfstring{$<$}{<}const C\&\texorpdfstring{$>$}{>}(b))}; where {\ttfamily a} and {\ttfamily b} are expressions of types {\ttfamily A} and {\ttfamily B} respectively, and {\ttfamily C} is {\ttfamily Common\+Type\+Trait\texorpdfstring{$<$}{<}A, B\texorpdfstring{$>$}{>}\+::type}.
\item If {\ttfamily @} is an assignment operator, {\ttfamily op(a, b)} is equivalent to {\ttfamily a = F(a, static\+\_\+cast\texorpdfstring{$<$}{<}const A\&\texorpdfstring{$>$}{>}(b))}, where {\ttfamily a} and {\ttfamily b} are expressions of types {\ttfamily A} and {\ttfamily B} respectively.
