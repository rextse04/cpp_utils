class utils\+::unique\+\_\+resource$<$ T, Sync, Semaphore, Shared\+Mutex $>$\+::permit}
A proxy through which the user uses the resource to enforce thread safety. 

{\ttfamily \doxylink{classutils_1_1unique__resource}{unique\+\_\+resource}} only issues a permit when there is available quota. The class has a private constructor to maintain the ownership of {\ttfamily \doxylink{classutils_1_1unique__resource}{unique\+\_\+resource}}. In other words, the user and other constructs cannot issue permits.
