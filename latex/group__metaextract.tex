\doxysubsection{Detailed Description}
A \href{Trait.html}{\texttt{ {\itshape Type\+Trait}}} and \href{Trait.html}{\texttt{ {\itshape Meta\+Trait}}} that extracts the template arguments from a template instantiation. 

{\ttfamily extract} is both a \href{Trait.html}{\texttt{ {\itshape Type\+Trait}}} and a \href{Trait.html}{\texttt{ {\itshape Meta\+Trait}}}. If {\ttfamily T} is a template instantiation, {\ttfamily extract\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}::type} is a tuple of its template arguments, and {\ttfamily extract\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}::trait} is a \href{Trait.html}{\texttt{ {\itshape Trait}}} which rebinds {\ttfamily T} to template arguments. Otherwise, {\ttfamily extract} is empty.
