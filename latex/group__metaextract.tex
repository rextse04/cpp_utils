\doxysubsection{Detailed Description}
Extracts the template arguments from a template instantiation. 

{\ttfamily extract} is both a {\itshape Type\+Trait} and a {\itshape Meta\+Trait}. If {\ttfamily T} is a template instantiation, {\ttfamily extract\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}\+::type} is a tuple of its template arguments, and {\ttfamily extract\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}\+::trait} is a {\itshape Trait} which rebinds {\ttfamily T} to template arguments. Otherwise, {\ttfamily extract} is empty.
