\doxysubsection{Detailed Description}
When the {\ttfamily std\+::sorted\+\_\+equivalent} flag is passed to any constructor overload that accepts it, it indicates that the range of keys passed to the constructor is sorted in non-\/decreasing order with respect to {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a387f5c52bb8be44a5dd202ca94790eea}{key\+\_\+compare()}}}, and the range of mapped values passed corresponds to it. The behavior is undefined if the flag is passed without satisfying this requirement.

When an allocator is passed to {\ttfamily alloc} in any of the following constructor overloads, the underlying containers are constructed with uses-\/allocator construction. Such overloads only participate in overload resolution only if {\ttfamily std\+::uses\+\_\+constructor\+\_\+v\texorpdfstring{$<$}{<}\mbox{\hyperlink{classutils_1_1segment__tree}{segment\+\_\+tree}}, Allocator\texorpdfstring{$>$}{>}} is {\ttfamily true}.

(1), (2)\+: Default constructors. Constructs an empty container adaptor.~\newline
(3), (4)\+: Copy constructors. Copy-\/constructs all underlying containers and functors.~\newline
(5), (6)\+: Move constructors. Move-\/constructs all underlying containers and functors. {\ttfamily other} is left in a valid empty state.~\newline
(7), (8)\+: Directly constructs the underlying containers using {\ttfamily keys} and {\ttfamily nodes}. The behavior is undefined if they do not conform to the internal layout of {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree}{segment\+\_\+tree}}}.~\newline
(9), (10), (11), (12)\+: Constructs the underlying containers from {\ttfamily keys} and {\ttfamily mapped}, sorts them if unsorted, and builds the segment tree. The behavior is undefined if {\ttfamily keys.\+size() != mapped.\+size()}.~\newline
(13), (14), (15), (16)\+: Inserts key-\/mapped pairs from {\ttfamily pairs}, which should be a range of {\ttfamily value\+\_\+type}, sorts them if unsorted, then builds the segment tree.~\newline
(17), (18), (19), (20)\+: Inserts key-\/mapped pairs from \mbox{[} {\ttfamily pairs\+\_\+begin}, {\ttfamily pairs\+\_\+end} ), which should be a valid range of {\ttfamily value\+\_\+type}, sorts them if unsorted, then builds the segment tree.~\newline
(21), (22), (23), (24)\+: Inserts key-\/value pairs from {\ttfamily pairs}, sorts them if unsorted, then builds the segment tree.
