\doxysubsection{Detailed Description}
A \href{Trait.html}{\texttt{ {\itshape Type\+Trait}}} that erases elements from a tuple type {\ttfamily Tuple} in the range \mbox{[}{\ttfamily Begin}, {\ttfamily End}). 

Both {\ttfamily Begin} and {\ttfamily End} can be negative indices, which are normalized relative to the tuple size.
