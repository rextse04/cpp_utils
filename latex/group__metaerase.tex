\doxysubsection{Detailed Description}
Erases elements from a tuple type {\ttfamily Tuple} in the range \mbox{[}{\ttfamily Begin}, {\ttfamily End}). 

Both {\ttfamily Begin} and {\ttfamily End} can be negative indices, which are normalized relative to the tuple size.
