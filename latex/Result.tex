{\itshape Result} is a generalization of instances of templates in {\ttfamily \texorpdfstring{$<$}{<}type\+\_\+traits\texorpdfstring{$>$}{>}}.\hypertarget{Result_autotoc_md18}{}\doxysubsection{\texorpdfstring{Requirements}{Requirements}}\label{Result_autotoc_md18}
A class type {\ttfamily T} is a {\ttfamily Result} if it fits into one of following categories\+:

\endhead
{\itshape Type\+Result}   &{\ttfamily T\+::type} names a type.    \\\cline{1-2}
{\itshape Value\+Result}   &{\ttfamily T} has a constexpr static data member named {\ttfamily value}.    \\\cline{1-2}
{\itshape Trait\+Result}   &{\ttfamily T\+::trait} names a class template which satisfies \href{Trait.html}{\texttt{ {\itshape Trait}}}, such that a {\itshape Type\+Result} or {\itshape Value\+Result} can be obtained in a finite number of steps for any well-\/formed sequence of nested template instantiations.   \\\cline{1-2}
\end{longtabu}
