\doxysubsection{Detailed Description}
Returns a (potentially proxy) reference to the mapped value of {\ttfamily key}. If {\ttfamily key} does not have a {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a387f5c52bb8be44a5dd202ca94790eea}{key\+\_\+compare()}}}-\/equivalent in {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a651253130fe6d6fc8bfc3b88e2851a9a}{keys()}}}, an exception is thrown with strong exception guarantee.
