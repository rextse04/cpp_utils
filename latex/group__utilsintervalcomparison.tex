\doxysubsection{Detailed Description}
Three-\/way comparison operator. 

Given intervals $I1$ and $I2$, $I1<I2$ if and only if $I1$ is a proper subset of $I2$. This defines a strict partial ordering on intervals.

The comparator is taken to be {\ttfamily std\+::less\texorpdfstring{$<$}{<}\texorpdfstring{$>$}{>}}.
