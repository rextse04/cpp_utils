Convenience variable template to make an \href{IntegerBehaviorProfile.html}{\texttt{ {\itshape Integer\+Behavior\+Profile}}} for bit shifts. 

For every relevant operator {\ttfamily @} and the corresponding functor {\ttfamily F} (supplied in template parameters), the synthesized functor {\ttfamily op} behaves as follows\+:
\begin{DoxyEnumerate}
\item If {\ttfamily @} is a binary operator, {\ttfamily op(a, b)} is equivalent to {\ttfamily F(a, b)}. In other words, {\ttfamily op} is identical to {\ttfamily F} in this case.
\item If {\ttfamily @} is an assignment operator, {\ttfamily op(a, b)} is equivalent to {\ttfamily a = F(a, b)}.
