An {\itshape Operator\+Functor\+Set} is a structural type that encapsulates and unifies type constraints and behavior for overloaded operators of a user-\/provided class type. {\ttfamily utils\+:\+:\texorpdfstring{$\ast$}{*}\+\_\+op} accepts {\itshape Operator\+Functor\+Set}(s) as template parameter and translates them into operator overloads, which is then expected to be inherited as part of the mixin pattern. Its use is most appropriate in a scenario where the child type is a wrapper around an underlying type for which such operations are well-\/defined.\hypertarget{OperatorFunctorSet_autotoc_md9}{}\doxysubsection{\texorpdfstring{Requirements}{Requirements}}\label{OperatorFunctorSet_autotoc_md9}
An {\itshape Operator\+Functor\+Set\+Template} is a class template declared as such by the library in the following format\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{\textcolor{keyword}{template}\ <\textcolor{keyword}{typename}\ Op1,\ ...,\ \textcolor{keyword}{typename}\ OpN,\ \textcolor{keyword}{typename}\ Traits1,\ ...,\ \textcolor{keyword}{typename}\ TraitsM>}
\DoxyCodeLine{\textcolor{keyword}{struct\ }OperatorFunctorSetTemplate;}

\end{DoxyCode}
 Each {\ttfamily OpI} corresponds to an operator supported by the template, denoted by {\ttfamily @\+\_\+I}; and a {\itshape trait set} (from {\ttfamily Traits1} to {\ttfamily TraitsM}), denoted by {\ttfamily Traits\+\_\+I}. All overloadable operators are classified into {\itshape types}, each corresponding to a trait set given by a fixed template parameter name, as specified below\+:

\hypertarget{OperatorFunctorSet_autotoc_md13}{}\doxysubsection{\texorpdfstring{Remarks}{Remarks}}\label{OperatorFunctorSet_autotoc_md13}
For brevity, in library documentation, when a template parameter {\ttfamily Traits} is required to be an {\ttfamily Operator\+Functor\+Set} for {\ttfamily utils\+:\+:\texorpdfstring{$\ast$}{*}\+\_\+op}, the meaning changes slightly. In this case, {\ttfamily Traits} is required to be an {\ttfamily Operator\+Functor\+Set} for each descendant of {\ttfamily utils\+:\+:\texorpdfstring{$\ast$}{*}\+\_\+op} that the user uses any of its supported operators on.
