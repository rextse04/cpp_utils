Comparison functions. 

Given endpoints $E1$ and $E2$, $E1<E2$ if and only if the set represented by $E1$ is a proper subset of the set represented by $E2$. This defines a strict weak ordering on endpoints.

Let $v$ be {\ttfamily this-\/\texorpdfstring{$>$}{>}value} and $ov$ be {\ttfamily other.\+value}. The program is ill-\/formed if there is not a restriction of {\ttfamily std\+::less\texorpdfstring{$<$}{<}\texorpdfstring{$>$}{>}} such that $v$ and $ov$ are in the domain. It is UB if such a restriction does not satisfy {\itshape Compare}.

Three-\/way comparison operator.

All endpoints are assumed to be right endpoints. The comparator is taken to be {\ttfamily std\+::less\texorpdfstring{$<$}{<}\texorpdfstring{$>$}{>}}.
