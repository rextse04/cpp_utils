class utils\+::segment\+\_\+tree$<$ Key, T, Compare, Sum, Identity, Key\+Container, Mapped\+Container $>$}
A key-\/immutable (multi-\/)associative container adaptor that supports linear-\/time construction and logarithmic-\/time search and aggregation. 

Segment tree is a data structure which partitions a set of keys into contiguous segments of lengths of powers of 2, where length is defined as the number of keys contained in the segment. {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree}{segment\+\_\+tree}}}, similar to {\ttfamily std\+::flat\+\_\+multimap}, is a container adaptor which stores keys and mapped values in two underlying containers of respective types {\ttfamily Key\+Container} and {\ttfamily Mapped\+Container}. Given $n$ key-\/mapped pairs, {\ttfamily keys} (of type {\ttfamily Key\+Container}) and {\ttfamily nodes} (of type {\ttfamily Mapped\+Container}) conforms to the {\itshape internal layout} of the class if and only if all of the following hold\+:
\begin{DoxyEnumerate}
\item {\ttfamily keys.\+size() == n} and contains the keys in non-\/decreasing order according to {\ttfamily Compare}. (Order of equivalent keys is unspecified.)
\item For $i\in\{0,...,n-1\}$, {\ttfamily node\mbox{[}i\mbox{]}} is paired with {\ttfamily keys\mbox{[}i\mbox{]}} in the original input.
\item Let $L(0)=n$ and $L(\ell)=\lceil L(\ell-1)/2\rceil$ for $\ell\in\mathbb{N}$. Further let $S$ be the partial sum of $L$, that is, $S(\ell)=\sum_{i=0}^{\ell} L(i)$. Denote by $h$ the height of the tree, that is, the smallest integer such that $L(h)=1$. Then, for $\ell\in\{0,...,h\}$ and $j\in\{0,...,L(h)-1$, $\mathrm{nodes}[S(\ell)+j]=\sum_{i=2^\ell j}^{2^\ell(j+1)-1}N[j]$, where $N[j]$ is {\ttfamily nodes\mbox{[}j\mbox{]}} if $j<n$ and the identity (defined by {\ttfamily Identity} otherwise, and the sum operator is defined by {\ttfamily Sum}.
\end{DoxyEnumerate}

{\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree}{segment\+\_\+tree}}} is only meaningful on mapped values in a monoid. More specifically, given an object {\ttfamily sum} of type {\ttfamily Sum} and {\ttfamily e} of type {\ttfamily Identity}, constructing the class is undefined unless all following semantic requirements are met\+:
\begin{DoxyEnumerate}
\item Associativity\+: For (possibly cv-\/qualified) objects {\ttfamily a}, {\ttfamily b} and {\ttfamily c} of type {\ttfamily T}, {\ttfamily sum(sum(a,b),c)} and {\ttfamily sum(a,sum(b,c))} are equivalent.
\item Identity\+: For any (possibly cv-\/qualified) object {\ttfamily a} of type {\ttfamily T}, {\ttfamily sum(a,e())}, {\ttfamily sum(e(),a)} and {\ttfamily a} are equivalent.
\end{DoxyEnumerate}

An {\itshape update record} is a container of type {\ttfamily update\+\_\+type} produced by some member functions of {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree}{segment\+\_\+tree}}} that represents extraneous updates to mapped values not reflected in the underlying containers. Although the internal layout of an update record is implementation-\/defined, it can be identified by a map $U$ from {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a651253130fe6d6fc8bfc3b88e2851a9a}{keys()}}} to {\ttfamily mapped\+\_\+type}. Any member function that accepts an update record behaves as if for any {\ttfamily k} in {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a651253130fe6d6fc8bfc3b88e2851a9a}{keys()}}}, the corresponding mapped value is {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a6b2b4b28ed13bae3f4bacd169aec497b}{sum()}}(at(k)+U\mbox{[}k\mbox{]})}. It is undefined to pass an object of {\ttfamily update\+\_\+type} to any such member function that is not produced by the same {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree}{segment\+\_\+tree}}}.

{\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree}{segment\+\_\+tree}}} meets the requirements of {\itshape Container}, {\itshape Reversible\+Container}, optional container requirements, and {\itshape Associative\+Container} except all operations that are only supported on non-\/const instances.

\doxyparagraph*{Iterator Invalidation}

Iterators and update records are invalidated by any non-\/const operation. It is undefined to use any invalidated iterator or pass invalidated update records to any member functions that accept them. In particular, invalidated update records still remain valid containers.

\doxyparagraph*{Additional Type Requirements}

In any member function that accepts a {\ttfamily multiplies} argument, it is undefined (unless ill-\/formed) to call to such function unless all the following hold true for any (possibly cv-\/qualified) object {\ttfamily a} of type {\ttfamily T}\+:
\begin{DoxyEnumerate}
\item {\ttfamily multiplies(a,0)} is equivalent to {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_aa56ea921a80f2ad2cc88cd38aaaa8a62}{identity()}}()}.
\item For any non-\/zero {\ttfamily n} of {\ttfamily size\+\_\+type}, {\ttfamily multiplies(a,n)} is equivalent to $\sum_{i=1}^n a$ (with respect to {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a6b2b4b28ed13bae3f4bacd169aec497b}{sum()}}}).
\end{DoxyEnumerate}
