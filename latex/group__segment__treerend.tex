\doxysubsection{Detailed Description}
Return an iterator to one past the last element in the reverse range of key-\/value pairs in {\ttfamily \texorpdfstring{$\ast$}{*}this}. 

The iterator points to the element preceding the first key-\/value pair (in normal order). The behavior is undefined if the iterator is dereferenced.
