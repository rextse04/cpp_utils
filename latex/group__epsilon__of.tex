\doxysubsection{Detailed Description}
A \href{Trait.html}{\texttt{ {\itshape Value\+Trait}}} that extends the definition of {\ttfamily epsilon} in {\ttfamily std\+::numeric\+\_\+limits} to integral types. 

The epsilon of a floating-\/point type is given by {\ttfamily Info\+::epsilon()}, while that of an integral type is {\ttfamily T(1)}. The classification of {\ttfamily T} is based on {\ttfamily Info}, which can be replaced by a class type that provides the same interface as {\ttfamily std\+::numeric\+\_\+limits}.
