\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename L, typename R$>$\newline
struct utils\+::interval$<$ L, R $>$}
An interval defined by a left endpoint and a right endpoint. 

The set represented by the interval is defined to be the intersection of that of the two endpoints.

\begin{DoxyWarning}{Warning}
In any member function which takes a {\ttfamily point} (resp. an {\ttfamily interval} {\ttfamily other}), the program is ill-\/formed if there is not a restriction of {\ttfamily comp} such that {\ttfamily point} (resp. {\ttfamily other.\+left}, {\ttfamily other.\+right}) and the two endpoints are in the domain. The behavior is undefined if such a restriction does not satisfy {\itshape Compare}. 
\end{DoxyWarning}
