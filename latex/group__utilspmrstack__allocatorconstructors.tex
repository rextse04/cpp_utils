Deallocates previously allocated memory and recycles it in a LIFO manner. 

Formally, let $(M_1,M_2,...,M_k)$ be the memory chunks previously allocated by any allocator equal to {\ttfamily \texorpdfstring{$\ast$}{*}this} which have not been {\itshape recycled}, in the order of allocation. A memory chunk is {\itshape recycled} if {\ttfamily allocate} can use its storage. As noted in the documentation of the class, deallocation in {\ttfamily \doxylink{classutils_1_1pmr_1_1stack__allocator}{stack\+\_\+allocator}} does not always recycle memory but may simply mark it as {\itshape removed}. Let \$\+D\+\_\+i\$ indicate if \$\+M\+\_\+i\$ has been removed for $i\in[k]$. A call to {\ttfamily deallocate} first finds $t$ such that {\ttfamily p} points to $M_t$, marks the chunk as removed, then recycles all chunks in the set $\{M_i\mid D_i,...,D_k\}$. \begin{DoxyRemark}{Remarks}
The alignment argument is unused. It is defined to deallocate a pointer obtained through aligned allocation without passing the required alignment. 
\end{DoxyRemark}
