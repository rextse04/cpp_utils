\doxysubsection{Detailed Description}
Get a reference to the underlying object of {\ttfamily x}. 

Conversion to references to underlying type.

Default-\/initializes {\ttfamily under\+\_\+}.

The static member function only has overloads for
\begin{DoxyEnumerate}
\item {\ttfamily \mbox{\hyperlink{conceptutils_1_1integer__like}{utils\+::integer\+\_\+like}}} types, and
\item {\ttfamily \mbox{\hyperlink{structutils_1_1integer}{utils\+::integer}}} instances with identical behavior profiles.
\end{DoxyEnumerate}

{\ttfamily \mbox{\hyperlink{structutils_1_1integer}{utils\+::integer}}} can be compared with an {\ttfamily \mbox{\hyperlink{conceptutils_1_1integer__like}{utils\+::integer\+\_\+like}}} type if and only if both have the same signedness (either both signed, or both unsigned).
