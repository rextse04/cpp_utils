\doxysubsection{Detailed Description}
Specifies that {\ttfamily T} is a strategy for traversing {\ttfamily ST}. 

A traverser strategy produces a value at every node (in {\ttfamily st}) the traverser visits, which is \char`\"{}joined\char`\"{} in a bottom-\/up manner to produce a final output from the traversal.
