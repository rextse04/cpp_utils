\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename T, bool Sync = false, typename Semaphore = std\+::counting\+\_\+semaphore$<$$>$, typename Shared\+Mutex = std\+::shared\+\_\+mutex$>$\newline
class utils\+::unique\+\_\+resource$<$ T, Sync, Semaphore, Shared\+Mutex $>$}
A user-\/provided resource that is capable of limiting and synchronizing access to it. 

Access to the underlying resource is done via \char`\"{}permits\char`\"{} that are issued by the class. 
\begin{DoxyTemplParams}{Template Parameters}
{\em Sync} & adds an internal mutex such that modifications via permit is synchronized (this should not be set to true if {\ttfamily T} is inherently synchronized, such as atomics) \\
\hline
{\em Semaphore} & a type that follows the interface of {\ttfamily std\+::counting\+\_\+semaphore} \\
\hline
{\em Shared\+Mutex} & a type that satisfies {\itshape Shared\+Mutex} (can be any type if {\ttfamily Sync} is false) \\
\hline
\end{DoxyTemplParams}
\begin{DoxyRemark}{Remarks}
In the context of this class, \char`\"{}read-\/only access\char`\"{} is synonymous with const reference, while \char`\"{}read/write access\char`\"{} is synonymous with non-\/const reference (to the underlying resource). 
\end{DoxyRemark}
