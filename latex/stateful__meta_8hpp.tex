\doxysubsection{Detailed Description}
This file contains utilities that enable stateful metaprogramming, which allows you to make compile-\/time {\bfseries{modifiable}} variables. This is done via a technique called \char`\"{}friend injection\char`\"{}.

In this file, compile-\/time variables are named by types. That is, such variables are defined, accessed and modified via the types they are associated with. Note that you are allowed to use the same type to name variables of different categories. For example, you can define a {\ttfamily const\+\_\+var\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}} and {\ttfamily \texorpdfstring{$<$}{<}i\texorpdfstring{$>$}{>}counter\texorpdfstring{$<$}{<}/i\texorpdfstring{$>$}{>}\texorpdfstring{$<$}{<}T\texorpdfstring{$>$}{>}} and they will be separate variables.
