\doxysubsection{Detailed Description}
Aggregate values in the given key or iterator interval. 

\begin{DoxyReturn}{Returns}
A value equivalent to that produced by the following process\+:
\begin{DoxyEnumerate}
\item Gather all key-\/value pairs $S$ contained in the given interval, in the order defined by {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a651253130fe6d6fc8bfc3b88e2851a9a}{keys()}}}.
\item Compute $\sum_{(k,v)\in S} v$ using {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a6b2b4b28ed13bae3f4bacd169aec497b}{sum()}}}. 
\end{DoxyEnumerate}
\end{DoxyReturn}
\begin{DoxyWarning}{Warning}
For overloads that accept an {\ttfamily update}, the returned value is unspecified (but still valid) if {\ttfamily \mbox{\hyperlink{classutils_1_1segment__tree_a6b2b4b28ed13bae3f4bacd169aec497b}{sum()}}} is not commutative on {\ttfamily mapped\+\_\+type}. 
\end{DoxyWarning}
