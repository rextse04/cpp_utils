\doxysubsection{Detailed Description}
Applies a ranged update to an update record. 

Suppose $K$ is the set of keys contained in the given interval. Let $U$ be the map that identifies {\ttfamily update} before the call. {\ttfamily update} is modified such that the new map $U\textnormal{\textquotesingle}$ satisfies the following\+:
\begin{DoxyEnumerate}
\item For $k\in K$, $U\textnormal{\textquotesingle}[k]$ is equivalent to {\ttfamily \doxylink{classutils_1_1segment__tree_a6b2b4b28ed13bae3f4bacd169aec497b}{sum()}(U\mbox{[}k\mbox{]},diff)}.
\item For $k$ in {\ttfamily \doxylink{classutils_1_1segment__tree_a651253130fe6d6fc8bfc3b88e2851a9a}{keys()}} but not in $K$, $U\textnormal{\textquotesingle}[k]$ is equivalent to $U[k]$. 
\end{DoxyEnumerate}
