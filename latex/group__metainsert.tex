\doxysubsection{Detailed Description}
Inserts a tuple-\/like type {\ttfamily Inserted} into a tuple type {\ttfamily Tuple} at index {\ttfamily Idx}. 

The index {\ttfamily Idx} can be negative, which is normalized relative to the tuple size.
