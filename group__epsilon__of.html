Detailed Description

A ValueTrait that extends the definition of epsilon in std::numeric_limits to integral types.

The epsilon of a floating-point type is given by Info::epsilon(), while that of an integral type is T(1). The classification of T is based on Info, which can be replaced by a class type that provides the same interface as std::numeric_limits.
