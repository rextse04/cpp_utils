Detailed Description

Get a reference to the underlying object of x.

Conversion to references to underlying type.

Default-initializes under_.

The static member function only has overloads for

  1. utils::integer_like types, and
  2. utils::integer instances with identical behavior profiles.

utils::integer can be compared with an utils::integer_like type if and only if both have the same signedness (either both signed, or both unsigned).
