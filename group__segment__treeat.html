Detailed Description

Returns a (potentially proxy) reference to the mapped value of key. If key does not have a key_compare()-equivalent in keys(), an exception is thrown with strong exception guarantee.

Exceptions
std::out_of_rangeIf key does not have a key_compare()-equivalent in keys()
