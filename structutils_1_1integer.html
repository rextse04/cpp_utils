Detailed Description

template<integer_like T, integral_behavior::profile IB = integral_behavior::sane, bit_behavior::profile BB = bit_behavior::sane, shift_behavior::profile SB = shift_behavior::standard>
struct utils::integer< T, IB, BB, SB >

An integer wrapper with added type safety and customizable behavior in arithmetic operations.

This class template is meant as a near drop-in replacement of built-in integers in the language. It provides better type safety: an explicit conversion call is needed when there is potential value change; and fully customizable behavior in arithmetic operations, which is controlled by the behavior profiles in template parameters. One may, for example, define overflow and underflow for signed integers to provide better safety guarantees.

The template is also flexible, in that the underlying type T can be any integer-like type. In other words, it is possible to use the class template on a non-standard big integer type as long as it meets all requirements specified in the standard for integer-like types. Specialize utils::is_integer_like to declare as a type as integer-like.

Template Parameters
IBIntegerBehaviorProfile for integral operations.
BBIntegerBehaviorProfile for bit operations.
SBIntegerBehaviorProfile for bit shifts.
