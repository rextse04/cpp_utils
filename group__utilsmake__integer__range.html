Detailed Description

Creates an integer sequence with custom Begin and Step values.

Template Parameters
TThe underlying integer type for the sequence.
EndThe exclusive end value of the range.
BeginThe starting value of the range (default: 0).
StepThe step size between elements (default: 1).
Remarks
Generates a sequence [ Begin , Begin+Step , Begin+2*Step , ...) up to End.
