Detailed Description

template<typename L, typename R>
struct utils::interval< L, R >

An interval defined by a left endpoint and a right endpoint.

The set represented by the interval is defined to be the intersection of that of the two endpoints.

Warning
In any member function which takes a point (resp. an interval other), the program is ill-formed if there is not a restriction of comp such that point (resp. other.left, other.right) and the two endpoints are in the domain. The behavior is undefined if such a restriction does not satisfy Compare.
