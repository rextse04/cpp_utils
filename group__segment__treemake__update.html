Detailed Description

Applies a ranged update to an update record.

Suppose \(K\) is the set of keys contained in the given interval. Let \(U\) be the map that identifies update before the call. update is modified such that the new map \(U'\) satisfies the following:

  1. For \(k\in K\), \(U'[k]\) is equivalent to sum()(U[k],diff).
  2. For \(k\) in keys() but not in \(K\), \(U'[k]\) is equivalent to \(U[k]\).
