Detailed Description

Takes ownership of the buffer and uses it for allocations.

Default-initializes under_.

Exceptions
std::bad_allocIf the internal control structure does not fit in the given buffer.
Note
The construction can throw even if space is not less than the size of the control structure depending on the alignment of buf.

Deallocates previously allocated memory and recycles it in a LIFO manner.

Formally, let be the memory chunks previously allocated by any allocator equal to *this which have not been recycled, in the order of allocation. A memory chunk is recycled if allocate can use its storage. As noted in the documentation of the class, deallocation in stack_allocator does not always recycle memory but may simply mark it as removed. Let $D_i$ indicate if $M_i$ has been removed for . Remarks
