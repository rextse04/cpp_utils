Detailed Description

template<typename T>
struct utils::interval_endpoint< T >

Represents an endpoint of an interval, consisting of a value and its type (open or closed).

Given a value \(v\) and a comparator \(C:D\times D\rightarrow\textit{boolean-testable}\) satisfying Compare,

Endpoint TypeSet Representation
Left Open\(\{x\in D\mid C(v,x)\}\)
Left Closed\(\{x\in D\mid\neg C(x,v)\}\)
Right Open\(\{x\in D\mid C(x,v)\}\)
Right Closed\(\{x\in D\mid\neg C(v,x)\}\)
Remarks
Note that we do not assume the domain of \(C\) to be \(D\).
