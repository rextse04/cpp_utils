Detailed Description

Aggregate values in the given key or iterator interval.

Returns
A value equivalent to that produced by the following process:
  1. Gather all key-value pairs \(S\) contained in the given interval, in the order defined by keys().
  2. Compute \(\sum_{(k,v)\in S} v\) using sum().
Warning
For overloads that accept an update, the returned value is unspecified (but still valid) if sum() is not commutative on mapped_type.
